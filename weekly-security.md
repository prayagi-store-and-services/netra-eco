# Weekly security release rule

Owner instruction, 24 October 2026: every Netra Ecosystem app must receive its weekly security patch on Saturday or Sunday, even when daily releases slip. The current cycle is due Sunday, 25 October 2026. All app websites must show this commitment. This change adds the commitment to the central website and the seven canonical app pages served by its shared app script. Separate legacy app websites still need an inventory and verified updates; this change does not claim they are complete. Every app owner must include this in release planning.

A release is not complete until the actual applicable app-security changes, tests, release APK, update path and website are checked. An audit, UI patch or version-only bump is not a security patch. An ordinary Android app does not install the vendor's OS security patch.

New app-security fixes may join the Sunday rollout after tests and review pass; the user confirmed option 1 on 24 October. The older bulletin/patch maturity requirement remains separate. No claim that this week's all-app rollout is complete is made here.

Applicable security fixes must also be added continuously to future apps in private development once their tests pass, without waiting for public launch. This does not authorize launching an unreleased app.
